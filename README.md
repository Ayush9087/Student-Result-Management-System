# 🎓 Student Result Management System

A console-based application built with **pure Python** to manage student results, grades, and perform searches.

## ✨ Features
- ✅ Add/Remove students with unique IDs
- ✅ Enter marks for multiple subjects
- ✅ **Automatic grade calculation** (A+, A, B+, B, C, D, F)
- ✅ Search students by name (case-insensitive)
- ✅ Display **top performers** based on average marks
- ✅ Save/Load data to/from **JSON file**
- ✅ Exception handling for robust input validation

## 🛠️ Technologies Used
- **OOPs**: `Student`, `Result`, `ResultManagementSystem` classes
- **Data Structures**: Dictionaries, Lists, List Comprehensions
- **File I/O**: JSON for persistent storage
- **Exception Handling**: `try-except` for error management
- **Strings**: Formatted output, grade display

## 🚀 How to Run
```bash
python student_result_system.py
```
